  },
  "professional_behavioral_signals": [
    {
      "signal": "observable professional behaviour (e.g. Collaborative leader, Data-driven decision maker)",

      "evidence": "supporting text from their profile"
    }
  ],
  "professional_motivators": [
    {

  },
  "personalization_guidance": [
    "specific, actionable guidance for writing the outreach email to this person 1",

    "guidance 3"
  ]

Safety rules:
- Only surface observable professional signals. Do not psychologically profile anyone.
- Do not infer or mention age, gender, ethnicity, health status, political views, or religion.

- Return ONLY the JSON object.
