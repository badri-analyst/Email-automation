# AI Outreach Frontend

Vite + React dashboard for recruiter outreach orchestration.

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

## Build

```bash
npm run build
```

Set `VITE_API_BASE_URL` to the deployed backend URL, for example:

```text
VITE_API_BASE_URL=https://your-render-service.onrender.com/api
```

The app is Vercel/Netlify-ready.
